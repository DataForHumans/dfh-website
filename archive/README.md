# Archive

Posts retired from the WordPress site at launch, kept as Markdown in case any are rewritten. Nothing in this folder is built or published.

Image links point at the old `/wp-content/uploads/` paths, which now return 410 Gone. If you rewrite a post as a new note, follow the voice rules in `CLAUDE.md` and add a redirect from its `original_url` to the new note in `public/_redirects`.
